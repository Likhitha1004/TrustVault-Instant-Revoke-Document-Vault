1. The Problem You Solved
Standard cloud drives have critical security flaws: 1. Broken Access Control (IDOR): URL ID manipulation exposes other users' confidential documents. 2. Stale Permissions: Revoked access lingers for minutes due to cached tokens. 3. Malleable Logs: Database records can be modified by rogue admins. TrustVault Solution: - Strict Zero-Trust ACL: Validates every request server-side (0ms stale window on revocation). - 404 on Unauthorized: Prevents document ID enumeration. - Append-Only SHA-256 Ledger: Chained cryptographic audit trail makes tampering mathematically impossible.
2. What Actually Works Right Now
100% Implemented & Verified in Production: - Auth & RBAC: JWT + bcrypt; distinct Admin, Owner, Viewer roles. - Zero-Trust ACL: Instant per-user read/edit permissions; 0ms revocation window. - Secure File Engine: Magic-byte inspection (%PDF validation; blocks disguised .exe/.html), streaming download proxy. - Atomic Bulk Operations: High-speed bulk delete in a single database transaction. - Cryptographic Audit Ledger: SHA-256 block chaining with PostgreSQL advisory locks (pg_advisory_xact_lock) preventing concurrency forks. - UI & Search: React 19 SPA with multi-criteria search (title, category, date, owner).

5. What The AI Got Wrong, And What You Fixed Yourself (25 Marks)
Critical AI flaws identified and manually fixed: 1. N+1 Query Overhead: AI used basic lazy loading (150+ queries, 1.1s latency). Refactored with joinedload/selectinload (2 queries, 82ms, 92.6% faster). 2. Audit Hash Race Condition: AI calculated hash in-memory; concurrent uploads caused ledger forks. Fixed using pg_advisory_xact_lock(77123991) for deterministic block serialization. 3. File Extension Spoofing: AI only checked .endswith('.pdf'). Implemented 2,048-byte physical magic-byte header inspection to block disguised executables. 4. IDOR Leakage: AI returned HTTP 403 on forbidden access. Enforced HTTP 404 to prevent valid UUID enumeration. 5. Slow Bulk Deletion: AI looped individual DELETE calls (150s+). Built atomic POST /api/documents/bulk-delete running in 3.82s.
